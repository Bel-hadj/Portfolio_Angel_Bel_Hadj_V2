Images de la page projet Emergent
(projet-indiewave.html + tuile dans index.html)

Statut : captures réelles en place (format .png).

- cover.png              → hero de la page + vignette sur la page d'accueil
- featured-artists.png   → section "Featured Artists" du vrai site
- catalogue.png          → section "Catalog" du vrai site
- spotify-playlists.png  → section "Playlists to explore" (vrais embeds Spotify)
- submit-track.png       → page "Submit your music"

Origine : captures d'écran réelles, prises automatiquement (Chrome headless)
à partir du vrai code du projet Emergent fourni par Angel (data.js, shared.js,
style.css, index.html, artists.html, submit.html, etc.), reconstitué à
l'identique dans un dossier temporaire hors du portfolio, sans aucune
modification du code d'origine. Rien n'a été inventé : ce sont les vraies
données (artistes, morceaux, playlists Spotify) telles que définies dans
data.js.

Format : .png (pas de .webp — aucun encodeur WebP disponible dans cet
environnement). Les <img> de projet-indiewave.html et de la carte index.html
référencent ces fichiers en .png.

Si tu remplaces ces images par de nouvelles captures (ex. après une mise à
jour du vrai site), garde exactement ces noms de fichiers, ou mets à jour les
chemins dans projet-indiewave.html et index.html en conséquence.

Fallback : si un de ces fichiers venait à manquer, le site affiche
automatiquement un état de secours propre (pas d'image cassée) — voir la
classe CSS .media-fallback dans styles.css et les attributs onerror sur
chaque <img> concernée dans projet-indiewave.html.
