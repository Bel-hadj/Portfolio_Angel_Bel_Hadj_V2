## Pour publier sur GitHub Pages

1. Crée un repository GitHub public, par exemple `portfolio`
2. Envoie tous les fichiers dedans
3. Va dans Settings > Pages
4. Source : Deploy from a branch
5. Branch : main / root
6. Ton site sera disponible sur :
   https://tonpseudo.github.io/portfolio/
