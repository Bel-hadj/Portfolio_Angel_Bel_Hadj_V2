DVD Filmothèque

Application web PHP / MySQL · 2024

Application web permettant de consulter un catalogue de films connecté à une base de données relationnelle.

Voir le site ↗ Voir sur GitHub ↗

Contexte

Projet réalisé dans le cadre de la SAE 203 (BUT MMI, IUT de Haguenau – Université de Strasbourg) : une filmothèque web connectée à une base de données MySQL.

Objectif

Créer une filmothèque dynamique permettant de consulter et rechercher des films à partir d’une base MySQL, avec plusieurs sections reliées entre elles plutôt qu’une simple liste.

Fonctionnalités

Catalogue de films 30 DVD avec affiche, note, prix et fiche détaillée.
Catégories Films et séries, avec le nombre de DVD par catégorie.
Nouveautés Derniers films ajoutés, triés par date.
Histoire du cinéma Frise chronologique des grandes périodes.
Commentaires Validation des champs et protection CSRF.
Recherche Par titre de film ou par réalisateur.

Design & développement

Conception et développement des pages de consultation (catalogue, détail, nouveautés, histoire) en PHP : les données sont récupérées via PDO (requêtes préparées) puis affichées par des templates Twig — jamais de HTML généré directement en PHP.

Les jointures SQL entre tables (films, genres, catégories) et la sécurisation des formulaires (CSRF) ont demandé plusieurs itérations — une bonne occasion de manipuler une vraie base relationnelle avec un moteur de templates plutôt que du PHP mélangé au HTML.
