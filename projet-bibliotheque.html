Web Development

DVD Filmothèque

Application web PHP / MySQL · 2024

Application web permettant de consulter un catalogue de films connecté à une base de données relationnelle.

Voir le site ↗ Voir sur GitHub ↗

Contexte

Projet SAE 203 (BUT MMI, IUT de Haguenau – Université de Strasbourg) : une filmothèque web connectée à une base de données MySQL, avec PHP, Twig et PDO.

Objectif

Aller au-delà d’une simple liste de films : plusieurs sections reliées entre elles, une base de données propre et des formulaires sécurisés.

Présentation du projet

Catalogue de 30 DVD filtrable par catégorie, avec recherche et commentaires sur chaque fiche film.

Fonctionnalités principales

Catalogue de films 30 DVD avec affiche, note, prix et fiche détaillée.
Catégories Films et séries, avec le nombre de DVD par catégorie.
Nouveautés Derniers films ajoutés, triés par date.
Histoire du cinéma Frise chronologique des grandes périodes.
Commentaires Validation des champs et protection CSRF.
Recherche Par titre de film ou par réalisateur.

Technologies utilisées

PHP Twig PDO MySQL HTML CSS

Architecture & fonctionnement

Chaque page récupère les données via PDO (requêtes préparées), puis les affiche via un template Twig — jamais de HTML généré directement en PHP.

Ce que j’ai réalisé

Conception et développement des pages de consultation (catalogue, détail, nouveautés, histoire), de la couche d’accès aux données (PDO) et de l’intégration des templates Twig.

Difficultés & apprentissages

Les jointures SQL entre tables (films, genres, catégories) et la sécurisation des formulaires ont demandé plusieurs itérations. Une bonne occasion de manipuler une vraie base relationnelle avec un moteur de templates plutôt que du PHP mélangé au HTML.
