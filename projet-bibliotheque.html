DVD Filmothèque

Application web PHP / MySQL

Application web permettant de consulter un catalogue de films connecté à une base de données relationnelle.

Voir le site ↗ Voir sur GitHub ↗

Contexte

Projet réalisé dans le cadre de la SAE 203 (BUT Métiers du Multimédia et de l’Internet, IUT de Haguenau, Université de Strasbourg) : concevoir un site de catalogue de DVD à partir d’une base de données MySQL, avec un moteur de templates.

Objectif

Construire une application complète — pas seulement une liste de films — avec plusieurs sections reliées entre elles, une base de données relationnelle propre, et des formulaires sécurisés.

Présentation du projet

Le site « Filmothèque » propose un catalogue de 30 DVD filtrable par catégorie, une section Nouveautés, une frise Histoire du cinéma, un espace Clients/Commandes, une recherche par titre ou réalisateur, et un système de commentaires sur les fiches films.

Fonctionnalités principales

Catalogue de films 30 DVD avec affiche, note, prix et fiche détaillée.
Catégories Films et séries, avec le nombre de DVD par catégorie.
Nouveautés Derniers films ajoutés, triés par date.
Histoire du cinéma Frise chronologique des grandes périodes.
Commentaires Formulaire avec validation des champs et protection CSRF, sur les DVD et les nouveautés.
Recherche Par titre de film ou par réalisateur.

Technologies utilisées

PHP Twig PDO MySQL HTML CSS

Architecture & fonctionnement

Chaque page PHP récupère les données via PDO (requêtes préparées), puis les transmet à un template Twig chargé de l’affichage — aucun HTML n’est généré directement dans les pages PHP.

Ce que j’ai réalisé

Conception et développement des pages de consultation (catalogue, détail, nouveautés, histoire), de la couche d’accès aux données (PDO) et de l’intégration des templates Twig, dans le cadre de ce projet universitaire.

Difficultés & apprentissages

La mise en place des jointures SQL entre les tables (films, genres, catégories) pour afficher une fiche détail complète a demandé plusieurs itérations, tout comme la sécurisation des formulaires (requêtes préparées PDO, protection CSRF sur les commentaires). Ce projet m’a permis de manipuler une vraie base de données relationnelle et de structurer un site avec un moteur de templates plutôt que du PHP mélangé au HTML.
